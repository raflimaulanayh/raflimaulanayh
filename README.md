## About

I build web products that make complex workflows easier to use. I’m a front-end-focused Software Developer with 3+ years of hands-on experience across 20+ professional, academic, and independent web projects.

My work includes ERP systems, company profile websites, LMS platforms, loyalty and event products, healthcare applications, and internal tools. I work primarily with React, Next.js, and TypeScript, building responsive production interfaces and integrating APIs. I’ve also independently built full-stack applications. I’m currently studying Information Systems at [SATU University](https://satu.ac.id).

I care about how products work for people, not just how they look. I apply accessibility, performance, SEO, and security practices, including semantic HTML, keyboard navigation, ARIA, image optimization, lazy loading, and vulnerability remediation.

AI agents are part of my development workflow. I use reusable agent skills and MCP tools, plan tasks, write structured prompts, organize project knowledge to give agents relevant context, and review generated code. This helps me work more efficiently while keeping quality in focus.

Outside development, I lead [One Technology](https://onetech.studio), where I create learning materials and mentor project teams across 6 divisions and 30+ members. I also founded [Nusacaraka Technology](https://nusacaraka.tech) and built and deployed its service platform.

Explore my portfolio and selected projects at **[raflimaulana.dev](https://raflimaulana.dev/)**
