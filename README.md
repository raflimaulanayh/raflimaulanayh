## About

I'm a **Software Engineer** specializing in building fast, resilient, and user-centric full-stack web applications. With over **4+ years of experience**, I have delivered **30+ production systems** for startups, SMEs, and public sector organizations, covering enterprise ERP solutions, scalable SaaS platforms, multi-tenant Learning Management Systems (LMS), e-commerce ecosystems, Smart School management systems, public service portals, and interactive Web3 applications.

I provide end-to-end technical execution across modern software ecosystems:

- **Frontend Architecture & Creative Web:** Core expertise in **Next.js (App Router), React, and TypeScript**, with versatile production experience across **Svelte, Nuxt.js, and Angular**. I build accessible, high-performance, and immersive interfaces using **Tailwind CSS, Three.js, GSAP, and Framer Motion**.
- **Backend, Systems & Web3:** Architecting robust RESTful and GraphQL APIs, microservices, and database schemas with **Laravel (PHP), NestJS (Node.js/TypeScript), and Go (Golang)** across MySQL, PostgreSQL, and MongoDB (NoSQL). Experienced with Headless CMS platforms like **Contentful** as well as **Web3 and dApp integrations**.
- **AI-Augmented Engineering:** Integrating modern AI workflows (**Claude, OpenAI/Codex, Cursor, GitHub Copilot**) alongside **MCP (Model Context Protocol)** and **Agent Skills** to rapidly scaffold modules, generate automated tests, and accelerate iteration, while keeping full accountability through rigorous manual code reviews and strict type safety.
- **Performance & Inclusivity:** Enforcing strict **Core Web Vitals** optimization, technical SEO best practices, and **WCAG Accessibility compliance** to ensure applications are universally usable and discoverable.

Explore in-depth case studies, live architectural breakdowns, and interactive demonstrations at **[raflimaulana.com](https://raflimaulana.com/)**.
